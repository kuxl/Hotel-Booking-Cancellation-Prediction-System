# Hotel Booking Cancellation Prediction System

A Machine Learning classification project that analyzes **hotel booking and customer information** to predict whether a hotel reservation will be **canceled or not canceled**. The project follows an end-to-end machine learning workflow covering data preprocessing, EDA, model building, evaluation, optimization, and deployment.

## 🎯 Objectives

* Analyze hotel booking and customer data
* Clean and preprocess the dataset
* Perform Exploratory Data Analysis (EDA)
* Identify factors influencing booking cancellations
* Build and compare classification models
* Evaluate model performance using classification metrics
* Optimize the final model
* Develop an end-to-end machine learning workflow

## 🔍 Key Analysis

* Hotel-wise booking and cancellation analysis
* Cancellation patterns based on lead time
* Customer and booking characteristics
* Market segment and distribution channel analysis
* Deposit type and cancellation patterns
* Previous cancellation behavior
* Average Daily Rate (ADR) analysis
* Customer type analysis
* Feature relationships and correlations
* Identification of important factors affecting cancellations

## 🤖 Machine Learning

The project treats hotel cancellation prediction as a **binary classification problem**.

**Target Variable:** `is_canceled`

* `1` → Booking Canceled
* `0` → Booking Not Canceled

Multiple classification models can be trained and compared using metrics such as:

* Accuracy
* Precision
* Recall
* F1-Score
* Confusion Matrix

## 🛠️ Technologies Used

**Python • Pandas • NumPy • Matplotlib • Seaborn • Scikit-learn • SciPy • Jupyter Notebook**

## 🔄 Project Workflow

**Data Collection → Data Cleaning → EDA → Feature Engineering → Feature Selection → Model Building → Model Evaluation → Hyperparameter Tuning → Final Model**

## 💡 Key Insights

The project analyzes booking behavior, customer characteristics, lead time, deposit types, market segments, previous cancellation history, pricing, and other booking attributes to understand cancellation patterns and develop a predictive machine learning solution.

## 📊 Dataset

* Approximately **119,000 hotel booking records**
* **30+ features**
* Numerical and categorical variables
* Hospitality / Revenue Management domain
